# 排版代码块

FFM 目前支持表格、slide、chain、accordion 语法。除表格外均以代码块包裹。

## 表格

表格通常用于展示结构化的数据对比。

### 基本语法

- 在第一行声明表头，使用 `|` 分隔各列。
- 在第二行声明分隔线，使用 `|` 和至少三个连续的连字符 `---`（数量可多于三个）表示列与列之间的分隔。
- 在后续书写表格数据。

其中，表头支持使用冒号 `:` 控制对齐方式：

- `:---` 表示左对齐。它和 `---` 效果相同
- `:---:` 表示居中对齐
- `---:` 表示右对齐

### 语法示例

#### 普通表格

```ffm
| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |
| 王五 | 28 | 广州 |
```

#### 带对齐的表格

```ffm
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |
| 长内容 | 长内容 | 长内容 |
```

### 排版建议

- 表格前后建议空行，以保证与其他元素正确分隔。
- 表格的单元格内容支持基本行内语法，如 `**粗体**`、`*斜体*`、`` `行内代码` `` 等。
- 不建议为对齐而在表格中写过多分割符或空格。

## slide

slide（滑块）通常用于长度相似、用于并列对比的项目。

### 基本语法

- 使用 ` ```slide ` 声明滑块。
- 使用分割线语法 `---` 切分区块。`---` 的前后必须有换行。

````ffm
以下是各社交媒体的比较：

```slide
**Ф social**
- 字数限制：3000 - 5000（字符数）
- 内容格式：Fuyeor Flavored Markdown

---

**Bluesky**
- 字数限制：300（字符数）
- 内容格式：纯文本

---

**Mastodon**
- 字数限制：视实例而不同，但大多数实例为默认的 500
- 内容格式：纯文本
```
````

### 排版建议

- 表格前后建议空行，以保证与其他元素正确分隔。
- 表格的单元格内容支持基本行内语法，如 `**粗体**`、`*斜体*`、`` `行内代码` `` 等。
- 不建议为对齐而在表格中写过多分割线或空格。

## chain

chain（思维链）通常用于 FAQ、思考步骤、时间轴、任务列表、教程步骤等场景。

### 基本语法

- 使用 ` ```chain ` 声明滑块。
- 使用独占一行的粗体（`**`）创建标题节点。

标题节点支持 Markdown 任务列表语法。例如：

- `**[x] 标题**` 会渲染为该标题已完成的样式（绿色节点）
- `**[ ] 标题**` 会渲染为该标题未完成的样式（黄色节点）
- `**标题**` 会渲染为默认样式（通常是紫色节点）

### 语法示例

#### 用于时间轴

````ffm
互联网从军用实验网络到全球互联，再到人人皆可参与的信息时代，经过如下发展：

```chain
**1960 年代：概念与雏形**
美国国防部提出「阿帕网」（ARPANET）概念，旨在建立一个分散、即使部分节点被摧毁也能继续通信的网络。

**1970-1980 年代：技术奠基**
TCP/IP 协议诞生，确立了计算机互相通信的通用语言，互联网的雏形逐渐形成。

**1990 年代：万维网与普及**
万维网（WWW）的出现让网页变得可浏览。互联网正式向公众开放，进入大规模商业化和大众化阶段。

**2000-2010 年代：蓬勃发展**
论坛、博客、社交媒体兴起。智能手机的普及让互联网真正装进了人们的口袋，随时随地都能上网。

**现在：智能互联**
全面迈入移动互联网、物联网、大数据和人工智能深度融合的时代。
```
````

#### 用于任务列表

````ffm
周末朋友生日派对的筹备进度：

```chain
**[x] 第一步：定好聚会场地**
已经预订好了大家一致同意的桌游店，定金也付过了。

**[x] 第二步：统计当天到场人数**
群聊里大家都接龙完毕，总共有 8 个人参加。

**[ ] 第三步：买好零食和饮料**
列好了购物清单，打算周六早上买完直接带去店里。

**[ ] 第四步：准备神秘生日礼物**
网购的礼物还在路上，预计周五下午送到。
```
````

#### 用于操作指南

chain 也非常适合用来写简单的操作指南。以下是作为操作指南的示例：

````ffm
如何给自己冲泡一杯香浓的挂耳咖啡：

```chain
**撕开滤袋**
沿着包装上的虚线小心撕开，并把两侧的纸质「耳朵」牢牢挂在杯沿上。

**第一次注水焖蒸**
用热水轻轻打湿咖啡粉，静置 20 秒，这时候能闻到浓郁的咖啡香气。

**分次注水完成**
继续缓慢倒入热水，直到杯子里达到你喜欢的浓度，然后取下滤袋扔掉。
```
````

## accordion

accordion（手风琴）推荐用于常见问题解答（FAQ）、隐藏详细内容以节约空间、点击查看答案、查看幕后小花絮等场景。

它使用和 chain 相同的语法，区别在于 **accordion 的内容默认是折叠隐藏的**（用户需要点击标题才会展开），并且它**不支持** Markdown 任务列表语法（也就是不能用 `[x]` 或 `[ ]` 来变颜色）。

> accordion 这个名字源自于网页设计中的一个形象比喻：就像手风琴的风箱可以自由拉开和合拢一样，这种组件也可以让内容自由地展开和收起，从而让页面保持干净整洁。

### 基本语法

- 使用 ` ```accordion ` 声明滑块。
- 和 chain 相同，使用独占一行的粗体（`**`）创建标题节点。

### 语法示例

#### 常见问题解答（FAQ）

````ffm
关于我们社区的一些常见小疑问：

```accordion
**如何加入我们的志愿者团队？**
点击首页右上角的「加入我们」填写一张简单的报名表，我们的管理员会在三个工作日内联系你。

**参与活动需要自己带工具吗？**
不需要哦，每次活动所需的全部材料和工具，我们都会在现场为你免费提供。

**如果临时有事去不了怎么办？**
没关系，只需在活动开始前 24 小时，在个人中心点击「取消预约」即可。
```
````

#### 隐藏详细步骤

````ffm
今天教大家做一道经典的「番茄炒蛋」，点击标题可以查看具体做法：

```accordion
**第一步：准备食材**
洗净 2 个番茄并切成滚刀块，敲 3 个鸡蛋加入少许盐打散备用。

**第二步：开火翻炒**
锅中热油，先将蛋液炒至定型盛出；再下番茄炒出沙，最后倒入鸡蛋混合均匀。
```
````

### 排版建议

- 在 chain 及 accordion 的内容区中，不建议使用 `#` 标题语法。
- chain 及 accordion 均使用独立单行 `**` 作为标题节点，因此正文中不应出现独立加粗。
- 如果在 chain 及 accordion 的内容区中出现代码块，则按照代码块规则，顶层使用更多反引号，例如 ` ````chain `
