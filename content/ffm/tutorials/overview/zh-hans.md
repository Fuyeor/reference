# 什么是 Markdown

Markdown 是轻量的标记语言，它允许使用者使用纯文本格式编写文档，通过简单的特殊符号来替代排版样式。文档可被转换为多种格式，如 HTML、PDF 和 Word 等。

```slide
### 💜 为什么要使用 Markdown

- **极简学习曲线**：只需掌握几个核心符号即可无门槛上手。
- **专注内容创作**：无需在编写文档时频繁将手移开调整字号、粗细和颜色。只需专注于文字内容，排版即可随手完成；也可以使用「所见即所得」的实时预览方式可视化编辑，兼顾效率与直观。
- **轻量与跨平台**：文件实质为纯文本格式，体积极小。任何文本编辑器都能直接打开、阅读并编辑内容。可无缝渲染成网页，或利用导出工具生成排版完美的 PDF、Word 等格式。
- **节约大模型成本**：使用 Markdown 编写的内容不含多余的样式代码，可在消耗最少 Token 的情况下被 AI 准确理解与处理。

---

### ❌ HTML 的局限性

- **适应性较差**：HTML 只存在于浏览器中，难以适应原生 App、终端等没有浏览器环境的场景。此外，如果直接在 HTML 里写 CSS 改变样式，则难以适应暗色模式等多主题环境；且经常根据目标平台渲染策略而被过滤。
- **存在隐私与安全风险**：HTML 文档允许直接夹带 CSS 样式、甚至 JavaScript 脚本。在本地打开未知的 HTML 时，可能会在后台触发未授权的远程网络请求（例如加载远程图片、XSS 攻击等），从而泄露用户的真实 IP 或其他隐私信息。
- **内容过于臃肿**：HTML 包含大量重复闭合的标签（如 `<div>`、`<p>`），语法结构冗长，在没有可视化辅助工具的情况下，极难进行纯手写输入和人类直观阅读。

---

### ❌ Microsoft Word 的局限性

- **结构不透明**：Word 文档（`.docx`）本质上是一个样式、文字、图片混合在一起的 XML 压缩包，难以直接快速提取出纯净的内容。
- **兼容性较弱**：同一份 Word 文档，在 Microsoft Office、WPS、LibreOffice 以及手机端打开时，经常会出现表格变形等样式不完全相同的问题。
- **存储开销大**：因为其中存在大量的元数据 XML 代码，导致即使只写了 1 个字符的 Word 文档，其底层体积也需要 13KB 左右，不便于海量存储和轻量分发。
```
